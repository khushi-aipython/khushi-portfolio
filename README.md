## 🎨 Design Approach

The portfolio was designed with a **minimal, warm, and personal visual style**.

A soft yellow background, simple typography, generous spacing, and a real personal photograph were used to create a balance between:

**Professionalism + Personality + Simplicity**

The goal was to make the important information easy to find while avoiding unnecessary visual clutter.
